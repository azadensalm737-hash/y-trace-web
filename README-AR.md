# Y-Trace — ربط Exa Search API

## مهم قبل التشغيل
- لا تضع مفتاح Exa داخل `public/index.html`.
- لا ترفع ملف `.env` أو مفتاح API إلى GitHub.
- نتائج البحث هي صفحات عامة مفهرسة، ولا تثبت ملكية رقم الهاتف أو هوية صاحبه.

## تشغيل محلي (لمن لديه Node.js)
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى ملف باسم `.env`.
3. ضع مفتاحك في `EXA_API_KEY` داخل `.env`.
4. نفّذ `npm install` ثم `npm start`.
5. افتح `http://localhost:3000`.

## نشره على خدمة استضافة Node
- ارفع ملفات المشروع إلى مستودع GitHub خاص أو عام دون ملف `.env`.
- أنشئ Web Service من المستودع في مزود استضافة يدعم Node.js.
- Build command: `npm install`
- Start command: `npm start`
- أضف متغير البيئة `EXA_API_KEY` في إعدادات الخدمة، وليس في ملفات الموقع.
- بعد النشر افتح رابط الموقع واختبر البحث.

## ماذا يفعل هذا النموذج؟
- يستدعي Exa من الخادم عبر `POST https://api.exa.ai/search`.
- يعرض العنوان والرابط والمقتطف والمصدر (اسم النطاق).
- يزيل روابط النتائج المتطابقة تمامًا.
- يضع حدًا أوليًا للطلبات لحماية الاستخدام.
- لا يسحب قواعد بيانات خاصة، ولا يتجاوز تسجيل الدخول أو القيود.
